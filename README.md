# GE 213 — الترم 481

موقع مقرر **GE 213 (Introduction to Engineering Design-2)** للترم 481. يجمع للطالب في مكان واحد:

- **التقويم:** بطاقة "هذا الأسبوع" بحصتيه والمطلوب فيهما، وشريط للأسابيع الخمسة عشر، ومواعيد التسليم.
- **الملفات:** ملفات المقرر بصيغة PDF مع حجم كل ملف، وملفات الواجب الحالي وما يجب تسليمه.
- **الحاسبة:** تقدير متوقع يتحدث فورًا حسب نظام العيوب، ويُحفظ في جهاز الطالب فقط.
- **الدليل:** نظام التقييم والعيوب والانضباط وأسباب الرسوب في صفحة واحدة.

الموقع ثابت بالكامل (بدون خطوة بناء)، ويعمل على GitHub Pages، ويدعم الوضعين الفاتح والداكن، ويعمل دون اتصال بعد أول زيارة.

## هيكل المجلدات

```
index.html              الصفحة الوحيدة (خفيفة: الوسوم والروابط فقط)
manifest.webmanifest    بيانات التثبيت كتطبيق على الجوال
sw.js                   عامل الخدمة للعمل دون اتصال
assets/
  css/                  tokens.css (الألوان والمقاسات) · base.css · components.css · pages.css
  js/app.js             الهيكل والتنقل والوضع الفاتح/الداكن
  js/pages/             calendar.js · files.js · calculator.js · guide.js
  js/lib/               التواريخ، ومنطق التقدير، وأدوات مساعدة
  js/components/        الأيقونات والمكوّنات المشتركة
  data/term-481.js      بيانات الترم: الأسابيع والحصص والتسليمات
  data/files.js         قائمة الملفات وربطها بالتقويم
  fonts/ icons/ vendor/ الخطوط المستضافة ذاتيًا، والأيقونات، ومكتبة React
files/                  ملفات PDF
docs/DESIGN-PLAN.md     خطة التصميم ونظامه
tools/screenshots.mjs   فحص بصري لكل الصفحات
```

## التشغيل محليًا

```bash
python3 -m http.server 8000
```

ثم افتح `http://localhost:8000/`. فتح `index.html` مباشرة من الملف لا يعمل، لأن المتصفح يمنع وحدات JavaScript من `file://`.

## تحديث البيانات

- **الأسابيع والتسليمات:** عدّل `assets/data/term-481.js`. رمز الحصة `4-1` يعني الأسبوع 4، الحصة الأولى.
- **أيام الحصص:** إذا حدّدت `CLASS_DAYS` (مثل `[0, 2]` للأحد والثلاثاء) يعرض الموقع تاريخ كل حصة وعدًّا تنازليًا بالأيام. وإذا بقيت `null` يعرض الأسبوع كاملًا.
- **الملفات:** ضع الملف في `files/` ثم أضف سطرًا في `assets/data/files.js` مع حجمه بالبايت.
- **ترم جديد:** انسخ `term-481.js` باسم الترم الجديد، وعدّل `TERM_START` والبيانات، ثم غيّر مسار الاستيراد في `assets/js/lib/dates.js`.
- **الخطوط أو الأيقونات أو مكتبة React:** عند تغييرها غيّر `VERSION` في `sw.js` حتى تصل النسخة الجديدة لمن زار الموقع سابقًا.

بيانات الحاسبة محفوظة في المتصفح بالمفتاح `ge213_data`. لا تغيّر اسمه ولا شكله حتى لا تضيع بيانات الطلاب.

## الفحص البصري

```bash
python3 -m http.server 8000 &
node tools/screenshots.mjs http://localhost:8000/
```

يلتقط السكربت كل صفحة على عرض 340 و390 و768 و1366 بكسل في الوضعين، ويحفظ الصور في `tools/out/`. ويبلّغ عن أي خطأ في الكونسول، أو تجاوز أفقي، أو نص أصغر من 12 بكسل. لمعاينة يوم معيّن أضف تاريخًا بعد الرابط، مثل `2026-09-27T09:00:00+03:00`.
